# 来源与交付范围

本目录是 H700 Android 10 最终保留源码的必要覆盖层与输入清单。AOSP、Allwinner、ARM Gralloc 等文件保留原有版权声明和许可；现有通知见各文件、原始厂商源码包和仓库的 `docs/THIRD_PARTY_INPUTS.md`。这里没有给所有第三方内容追加统一授权。

`source-manifest.json` 的三类输入：

- `repository`：当前 Git 中的适配源码或此前已经公开的冻结源码/资源。
- `source`：从解压后的指定版本 Android 基础树复制，按 SHA256 验证；没有再次上传这些未修改文件。
- `image`：从网盘 0.0.1 镜像提取的驱动、固件、桌面与壁纸。文件保持外部输入，不另行提交到 Git。

桌面提取自已签名的 0.0.1 系统，作为预编译应用输入，再由构建者自己的 platform 密钥签名；不声称取得桌面应用完整源码。H700 内核、DTB、bootloader 及基础 ramdisk 沿用指定镜像，本入口重编 Android 用户空间，不等于所有启动组件从源码重编。

签名私钥和个人 ADB 授权不在覆盖层中；打包器重新创建空 userdata，不导入镜像原有 userdata。构建者应自行保管签名身份，并确认其使用、分发第三方输入的权限。
