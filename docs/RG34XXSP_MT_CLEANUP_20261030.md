# MT 管理器按键初测与试验应用清理

日期：2026-10-30。检查点：`baseline/rg34xxsp-mt-app-cleanup-20261030`。当前 RG34XXSP / H700 / 2GB / Android 10 开发卡已安装官方 MT 管理器 2.26.10，并按用户指令卸载未入选的试验应用。

**结论：MT 常用文件操作可用，但没有通过全程十字键验收。** 底栏的新建等按钮和侧栏顶部按钮存在方向焦点断点，仍需 Select 长按呼出的虚拟鼠标辅助。[首批六款预装名单](FIRST_PREINSTALL_BATCH_20261030.md)保持不变，MT 先作为补充文件管理候选。

## 安装版本

从 [MT 官方下载页](https://mt.cc/download/) 的正式版入口取得 APK，实际重定向至小米分发服务器。包名 `bin.mt.plus`，版本 2.26.10 / 26101061，最低 API 21、target API 30，包含 armeabi-v7a。已按 Android API 29 验证 APK v2 签名，安装后读回 SHA-256 一致。没有修改、重新签名或上传 APK。

版本、来源、体积、签名指纹及脱敏结果见 [应用锁](app-tests/rg34xxsp-mt-20261030/app-lock.json)。

## 按键测试结果

使用已核对身份和 USB transport 的当前样机，通过原 ANBERNIC 控制器的 evdev HAT、A/B、Select 注入；不是触摸点击、无障碍 CLICK 或虚拟鼠标代操作。每步观察焦点/画面，文件变更仅针对 `/sdcard/Download/H700_MT_TEST_20261030/` 内自制夹具。

| 路径 | 结果与边界 |
| --- | --- |
| 首次协议、存储授权 | 方向键与 A 完成 |
| 浏览目录、长列表滚动 | 通过；下移到屏外目录会自动滚动，A 进入、B 返回 |
| 左右双窗口 | 方向左/右切换通过，两侧可分别浏览源目录和目标目录 |
| 文本查看 | A 打开 UTF-8 中英测试文本，B 返回；编辑保存流程未完整验收 |
| 文件操作菜单 | **长按 A 约 1.2 秒**打开；方向选择、A 确认、B 返回 |
| 复制 | 原目录复制到另一窗口的 destination；文件内容哈希一致 |
| 重命名 | `sample.txt` → `g.txt`，内容哈希不变；输入通过系统十字键软键盘完成 |

| 侧栏列表 | 从文件列表顶端上移到工具栏，再向左到侧栏按钮、A 打开；目录及工具列表可向下滚动，B 关闭 |

| **侧栏顶部“夜间模式/更多”** | **未通过**：焦点落在整个头部 ViewGroup，向右未进入子按钮；没有据此声称设置入口或设置内容均通过 |

输入框有额外步骤：输入后先在软键盘选“完成/下一个”，再 B 收起键盘，随后方向选择对话框按钮。仅直接 B 隐藏键盘时，方向键可能仍在输入框内移动光标。重命名和 ZIP 对话框已按完整路径完成。

以上是远程控制器事件验收，实体长按手感与屏幕可读性仍待用户确认。APK 分析、终端、插件、远程管理、全部设置和所有高级业务不在本次通过范围；没有开通会员或登录 MT。未修改全局按键映射、密度或 MT 二进制来补焦点。
