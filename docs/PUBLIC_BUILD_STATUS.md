## 公开入口与 Test10 的区别

`tools/public_build/` 仍从指定 **0.0.1 提取 kernel、DTB、bootloader 和基础 ramdisk**，然后配合新编译的 Android 分区打包。它没有把作者后续手动机型启动器、各面板补丁、三档音量试屏、默认交换空间及新摇杆模块的增量构建链自动接成一个干净克隆入口。

因此，按公共指南得到的 `ROC_OS_ARM64_community.img.gz` 不能被称为 Test10 的逐字复刻，也不保证具有同样的十二机型启动行为。最新启动、型号表、翻盖、摇杆、swap、封装与验证源码及依赖关系见 [Test10 源码地图](TEST10_SOURCE_MAP.md)。同步这些源码使当前实现可查阅，不自动构成完整的公开重现验收。

若需要从源码重新构建全部 H700 启动组件，还需各组件对应版本、配置及完整流程；当前没有宣称所有 bootloader、kernel 和厂商二进制都由本项目从源码重编。大型源码、镜像不提交 Git，官方私钥也不是公共构建输入。

## 可运行的轻量核对

在仓库根目录使用 Python 3.11+：

```sh
python3 tools/public_build/validate_manifest.py
python3 tools/public_build/test_public_build.py
```

这两项只证明各自的输入和工具范围。完整生产构建、整卡验证、实机验收和独立公开重现应各自保留实际结果；不要用其中一项代替其余项目。
