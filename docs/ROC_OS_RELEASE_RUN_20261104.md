# ROC OS 发行收口与实体复验（2026-11-04）

本轮在 `24ea1f0` 发行准备基线上继续。用户已返回，实体测试恢复；目标为争取发行，但所有正式发行门禁仍以真实产物与测试结果为准。旧镜像、失败记录、工程回退与 SPACE_REVIEW 用户修改保留。

## TF2 实体热拔插

安全卸载三个 FAT 卷后，用户实际拔出并插回同一张 TF2 卡。拔出时块设备及 vold 磁盘消失；插回时按 CID 与 sdc2 控制器重新识别，三个卷自动挂载。最大卷内 66 个测试文件通过底层及共享存储路径逐一核对 SHA-256，结果一致。未格式化、修复或改分区。

这通过的是当前工程卡、该张旧 FAT 卡的一轮热拔插与文件保留。其他文件系统、普通应用 SAF、满盘、异常断电、其他容量卡与最终发行镜像仍需独立验收。之后再次安全卸载三个卷，用户移除 TF2，按菜单关机、拔 USB、等 10 秒后按电源开机并接回 USB，确认中文、AT4K 和 A 解锁正常。

新的内核 boot ID、TF1 身份及关键 SHA 核对通过；TF1 的 66 个测试文件在共享及底层路径仍全部一致，TF2 块设备不存在。`init.svc.vendor.roc-thermal=running`，Thermal 实际 UID1000、hal_thermal_default 域，Android ThermalHAL2.0 connected 与 HAL Ready 均为 true。这补齐了当前工程卡的一轮 Thermal 冷启动自动拉起证明，未计作最终 user 镜像验收。

## 签名身份

用户明确授权创建 ROC OS 专用密钥。一次性创建 `production-v1` 的 releasekey、platform、shared、media、networkstack 五组 RSA4096 密钥；私钥只在仓库外私有目录，生成工具拒绝覆盖现有身份。证书与私钥公钥匹配验证通过。公开证书摘要见本轮结果锁；不上传私钥或备份包。

标准 OpenPGP AES256 加密备份已通过解密回读和独立篡改样本拒绝测试。原包复制到用户指定的另一 USB 介质并核对 SHA-256 一致。用户选择将恢复口令文件也保存到该介质同一目录，已明确其持有人即可解密。随后实际从外置介质读取密文与口令，在内存中解密并核对全部 12 个归档成员，均与原件一致；未将解密私钥提取到外置盘或输出到日志。尚未使用这些新密钥签署或发行系统。

## 初始化去 root 迁移

新增平台签名的 ROCProvisioning 系统应用，使用独立应用 UID，不共享 system UID，不启动 shell。通过 WRITE_SECURE_SETTINGS、MANAGE_ROLE_HOLDERS 等系统接口设置首次默认输入法、HOME、导航服务和品牌名称。已完成状态下保留用户后续设置；自定义设备名称不覆盖。旧 root 工厂及品牌脚本取消安装，增量 staging 中的旧文件移到产物外保留。

首个草案以启动计数判断是否已经配置，可能在首次配置中断后误跳过，已主动停止构建且未部署。修正版只接受自身完成记录或明确验证过的前代迁移标记。前代标记仅供已验证旧卡迁移；干净 userdata 必须实际执行首次配置。保留被拒绝草案、终止日志和原产物。

修正版构建 `h700-low-pressure-20261104-222540` 成功，images-result-v18/prepare-v22；18 项主机用例通过，包含初始化策略。随后 `h700-low-pressure-20261104-223629` / round2-audit-v13 通过 121 项实际分区检查；36 启动根、548 ELF、631 命名空间状态及 41 个早期对象无依赖缺项。新 APK 与 SystemUI 平台签名一致，四个旧脚本/RC 不在新分区中。构建 10 分 29 秒、峰值 5GiB/445.7MiB swap；审计 1 分 47 秒，资源上限保持。检查数因移除旧工厂脚本检查、改为新应用检查发生变化，不能用总数直接比较覆盖率。

真机在严格身份/SHA 守卫下安装了审计提取的工程签名 APK。验证旧完成记录后测试显式迁移，随后撤回临时迁移标记，测试自身完成记录下的重复调用；现有设置均保持。另在所有目标默认项已经选定的前提下，仅清空新应用自身数据，执行首次配置 API 分支并成功提交完成状态，设置仍一致。实际为独立应用 UID、platform_app 域，非 root、非共享 system UID；所需签名权限真实获授。

这不是空白 userdata 的工厂首启，也未覆盖清空 HOME 角色后的首次分配。测试通过的 APK 暂在当前卡 data 层，加入备份过的私有运行守卫；卡上的旧 root 初始化 RC 尚未替换，不能把当前卡称为已经完成全部去 root 的 user 系统。本轮冷启动发生在安装该应用之前，其实际开机广播自启和正式换签后的干净首启尚未验收。

## 仍阻断正式发行

独立 user 产品尚未编出；SELinux enforcing、认证 ADB、root/控制台关闭、正式 APK 全量签名审计和实际 boot 参数仍未验收。当前真机仍是带补丁的 eng/Permissive 系统。充电/低电/持续负载温控、深睡与唤醒、救援实卡、许可及同一最终镜像的完整回归继续开放。不能把源码增量或历史 GSI 验收当作新发行包已通过。

原始设备身份、文件清单、备份路径、冷启动前状态与构建日志仅留忽略的 `out/source64-release-run-20261104/` 及原有构建目录。
