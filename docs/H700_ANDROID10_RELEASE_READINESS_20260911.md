# H700 Android 10 发布就绪清单

日期：2026-09-11  
适用对象：RGSP/H700 Android 10，方案 A，64GB 单卡原型

## 当前判断

最新实测为主卡槽启动失败：用户按电源键黑屏、无可见反应。
此前“完整写卡校验完成”的表述撤回，旧 p1-p4 校验日志不能证明后来
补充的启动区已写入。详见 `H700_ANDROID10_SINGLE_CARD_FAILURE_20260911.md`。
以下后续计划保留，但须先闭合实卡启动区取证和启动修复。
方案 A 指安卓卡占用 TF1 主卡槽、移除两张原工作卡，不是拔空主卡槽。

22:31 只读回读现已证明 Boot0 区存在，但 boot 分区与 Brandy 启动包
候选位置重叠；检查器明确拒绝当前布局。修复未部署，等待原 Linux 卡
完整启动包取证。此结果不改变发布阻断状态。

## 四阶段状态

### 阶段 1：固定镜像与 Fix72 回归

**当前：基本完成，仍需单卡启动后的最终回归。**

已完成：可回退工作卡、TF2 vendor/data 备份与修复、codec/audio 持久候选、
p1 修复、Fix72 codec/WebView 暖启动回归。单卡 p1-p4 有历史回读日志，
但不作为后来修订启动区的完整部署证据。

仍需：单卡首次启动后的挂载和日志检查，确认 p1/p2/p3/p4 均来自单卡，
确认不依赖旧双卡 handoff；保留上机前后的启动日志和分区清单。

### 阶段 2：独立启动方案

**当前：实机启动失败；启动区是否按修订方案写入待只读核实。**

必须验证安卓卡在 TF1 主槽、原工作卡移除后的启动、重启、冷启动，第二槽的
识别/挂载/安全卸载，以及失败后重新插入原 TF1 Linux 卡的恢复路径。

在这些项目完成前，只能称“方案 A 原型卡”，不能称“用户可直接刷写的
正式独立镜像”。

### 阶段 3：冷启动、持续运行、设置、Wi-Fi

**当前：暖启动和网络基础能力已验证，正式验收未完成。**

Wi-Fi 自动重连、百度 HTTP/HTTPS、Settings 打开与返回、核心 Android
进程稳定样本已通过；音频软件播放链路也已有持久化暖启动证据。

仍需完成至少 10 次真正断电冷启动、正式 60 分钟持续运行、设置修改后
重启保存、睡眠/唤醒、亮度、电池/USB 状态、异常断电恢复，并复查此前
视频中的画面闪烁，区分电源、显示栈和 TF 卡因素。

### 阶段 4：声音、电源、按键和 APK 流程

**当前：音频暖启动证据较强，其余仍需实机验收。**

声卡权限和 codec 配置已持久化，低幅测试音和 QQ Music 软件播放指针
曾正常推进，用户已确认音频没有问题。

仍需完成扬声器/耳机/HDMI（若纳入产品范围）、A 键解锁、A 确认、B
返回、HOME 返回桌面、X/Y 功能，以及仅用实体键完成 X-plore 打开、
授权、选择 APK、安装、启动和回退。还需验收亮度、音量、电源键、休眠
唤醒和异常应用退出。

## 发布阻断项

以下任一项未完成，都不应对外发布：

1. 单卡启动仍依赖原 Linux 工作卡、旧 marker、串口命令或人工修复。
2. 没有可验证的失败回退路径，或唯一原厂恢复卡未保留。
3. 分区布局、镜像哈希、写卡工具和用户刷卡步骤无法复现。
4. 冷启动、持续运行、音频、电源或实体按键存在未解释失败。
5. APK 安装/授权只能依靠触摸、ADB 或开发者 root 权限。
6. 调试 overlay、临时 codec 文件、测试 APK 或私有凭据残留在发布包。
7. 没有明确说明第二 TF 槽是否支持扩展卡，以及 data/ROMS 的容量和
   首次启动行为。

## 后续执行顺序

1. 上机记录方案 A 首次启动：UART、启动时间、`sys.boot_completed`、
   分区挂载、Wi-Fi 和第二卡识别。
2. 完成重启与断电冷启动矩阵，保留每次结果和失败日志。
3. 完成第二 TF 槽扩展卡测试，不写入或破坏单卡系统分区。
4. 完成音频、电源、睡眠唤醒、按键和 APK 纯实体键回归。
5. 做 60 分钟稳定性和无网/磁盘满/异常退出等基本场景测试。
6. 固化最终源镜像、分区表、启动区、写卡脚本、校验脚本和回退包。
7. 生成发布包：`SHA256SUMS.txt`、容量要求、Windows 刷卡说明、首次
   启动说明、扩展卡说明、恢复说明和已知问题。
8. 最后再做 AT4K 720x480 小尺寸布局精修，并重新跑启动、内存和输入回归。

## 发布包应包含

- 经过验证的完整单卡镜像或等价分区镜像集；
- 启动区/boot/system/vendor/data/ROMS 的布局说明；
- 自动识别目标卡并拒绝误写其他磁盘的写卡工具；
- 写后分区、容量和 SHA-256 校验工具；
- 原厂 Linux 回退卡说明，不把它与 Android 发布卡混用；
- 版本号、构建日期、源码/补丁清单和所有已知限制；
- 明确标注“RGSP 专用”，除非第二机型也完成独立验证。

## 不纳入本次发布的内容

- 尚未验证的其他 H700 机型；
- 未完成 ABI 验证的 GPU/HWC/视频硬件解码能力；
- 依赖 GMS、触摸屏或在线服务才能工作的功能；
- 未经授权重新打包的第三方 APK 或 AT4K 许可状态；
- 仅通过静态分析得到、尚未在 720x480 实机验证的 UI 改动。
