最终10项用例通过：实际紧凑GPT、错误UUID/CRC拒绝；备份损坏在写前拒绝；符号/硬链接及设备拒绝；普通文件恢复与保护范围保持；源码漂移/新增识别；安全属性Make解析；user/外部密钥门禁；测试证书拒绝。另在64MiB真实ext4文件系统中写存档、破坏超级块、恢复后执行fsck并读回存档，均通过。GPT大文件是WSL ext4上的稀疏普通文件，不写工作卡、不在NTFS生成整张大镜像。

对本地已冻结32,434,554,368字节整卡raw文件只读校验通过，userdata范围20GiB和UUID匹配。PowerShell入口的带空格路径/非法镜像拒绝也通过。仍没有物理卡上的恢复、断电恢复或升级验收。
