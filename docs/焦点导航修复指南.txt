=== RGSP焦点导航修复 - 分步执行指南 ===

【方法1：通过串口手动执行（推荐）】
每次只发送一条命令，等待执行完成：

1. 启用TV UI模式：
   settings put global ui_mode_type 4

2. 重启SystemUI生效：
   pkill -f systemui

3. 验证模式：
   settings get global ui_mode_type

预期输出应该是：4

【方法2：获取IP后通过WiFi ADB执行】
需要先通过串口启用WiFi ADB：

1. 设置ADB端口：
   setprop service.adb.tcp.port 5555

2. 重启ADB：
   stop adbd && start adbd

3. 在电脑上连接：
   adb connect <设备IP>:5555

4. 推送并执行修复脚本：
   adb push tools\rgsp_focus_fix.sh /data/local/tmp/
   adb shell sh /data/local/tmp/rgsp_focus_fix.sh

【方法3：在设备上手动设置】
如果能在设备上操作：
1. 设置 → 关于 → 连点"版本号"7次启用开发者选项
2. 设置 → 开发者选项 → 启用USB调试
3. 然后用USB线连接电脑执行方法2的步骤4
