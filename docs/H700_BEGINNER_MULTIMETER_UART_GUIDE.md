# H700 零基础万用表与 UART 定位指南

更新日期：2026-08-29

适用仪表：德力西 DT9205A-Pro（或档位相近的数字万用表）  
适用任务：RGSP、RG34XX 系列、H700 投影仪/开发板的低压测量和 UART 定位

## 1. 当前表笔接法

- 黑表笔插 `COM`。
- 红表笔插最右侧 `VΩHz`。
- 本项目不要把红表笔插进 `mA` 或 `20A` 孔。
- 不测市电、充电器内部高压区或投影仪电源板的市电侧。
- H700 主板只使用低压直流电压档、蜂鸣/通断档和电阻档。

> 红表笔一旦插在电流孔，不能并联触碰电源或主板测试点。这样会近似短路，可能烧保险丝、烧表、损坏主板或电池。

## 2. 必须遵守的四条规则

1. **电压可以带电测；通断和电阻只能断电测。**
2. 转动档位或移动夹线前，先把红表笔离开主板。
3. 测主板电压时，黑表笔固定在已确认的 GND，只移动红表笔。
4. UART 永远不接 USB-TTL 的 `5V`；初次连接也不要接 `VCC/3.3V`。

锂电池正负极短路可能引起高温或起火。拆机测量时摘下戒指、手表等导电物，主板放在绝缘桌垫上，并固定好，避免表笔滑动同时碰到两个焊盘。

## 3. 第一次练习：不要先拿 H700 主板试

### 3.1 蜂鸣档自检

1. 断开任何被测物。
2. 将旋钮转到面板左下方的蜂鸣器/二极管符号档。
3. 两支表笔悬空：应显示超量程或高阻状态，例如 `1`、`OL`。
4. 两支金属笔尖互相接触：应蜂鸣，显示接近 `0 Ω`。

表笔自身可能有约 `0.1-0.8 Ω` 电阻，这不是故障。记录两笔短接时的读数，后面判断主板 GND 时用于扣除参考。

### 3.2 用 AA/AAA 电池练习直流电压

1. 将旋钮转到面板右上白色的 `V⎓ 20` 档。`V⎓` 是直流电压，不是黄色的 `V~` 交流档。
2. 黑表笔接电池负极，红表笔接电池正极。
3. 普通新碱性电池通常会显示约 `1.5 V`；充电电池通常约 `1.2-1.4 V`。
4. 交换两支表笔后，数字前应出现负号，绝对值基本不变。

完成这两项后再测主板。

## 4. 在 H700 主板上找 GND

整个步骤必须在主板完全断电后进行：拔充电器、USB 和电池；若电池不方便拆，至少不要使用蜂鸣/电阻档在板上乱扫。

### 4.1 参考地选择

以下金属通常是 GND 候选，但必须实测确认：

- USB 接口的金属外壳；
- HDMI 接口的金属外壳；
- microSD 卡座的大面积金属外壳；
- 螺丝孔周围裸露铜环；
- 电池负极焊盘。

### 4.2 确认方法

1. 万用表置蜂鸣/通断档。
2. 黑表笔接一个接口金属外壳。
3. 红表笔依次触碰另一个接口外壳和待测焊盘。
4. 多个外壳之间稳定蜂鸣且读数接近表笔短接值，可将它们作为公共 GND。
5. 某测试点与这些外壳稳定接近 `0 Ω`，才可标记为 GND。

短促响一下随后停止，可能是电容充电，不等于该点是 GND。真正的 GND 通常会持续蜂鸣，并与多个已知地之间保持极低电阻。

## 5. 测 UART 候选点电压

### 5.1 准备

1. 将旋钮转到右上白色 `V⎓ 20` 档。
2. 用夹子把黑表笔固定在已确认的 GND。
3. 红表笔只露出约 1-2 mm 金属尖端；可用热缩管或胶带包住其余部分。
4. 给每个候选焊盘编号，例如 `TP1`、`TP2`、`TP3`、`TP4`，先拍清晰照片。
5. 用设备原本的电池或电源正常开机，不用万用表给主板供电。

### 5.2 逐点测量

红表笔一次只碰一个焊盘，分别记录：

- 关机但接电时的电压；
- 按下电源后的瞬间电压；
- U-Boot/开机 Logo 阶段电压；
- 卡 Logo 后的稳定电压。

常见现象只能用于初筛：

| 读数 | 初步判断 |
|---|---|
| `0 V`，断电后对地近 `0 Ω` | GND |
| 稳定约 `3.3 V` | 3.3 V 电源或处于空闲高电平的 UART |
| 稳定约 `1.8 V` | 1.8 V 电源或 1.8 V UART，不能直接接普通 3.3 V TX |
| 开机时在约 `3.3 V` 与较低读数间变化 | 很可能是 UART TX，但万用表只能看到平均值 |
| 开机时在约 `1.8 V` 与较低读数间变化 | 可能是 1.8 V UART TX，需要 1.8 V 适配器/电平转换 |
| 稳定约 `5 V` | 电源点，避开，不是应直接连接的 UART 信号 |
| 漂浮、跳变或接近 `0 V` | 可能是 RX、未连接测试点或其他信号，不能只凭此定性 |

万用表无法区分“3.3 V 电源”和“空闲为 3.3 V 的 UART”，也无法解码数据。最终必须使用 USB-TTL 或逻辑分析仪验证。

## 6. USB-TTL 的安全接法

建议购买：

- 带明确 `3.3 V TTL` 电平选择的 CP2102N、FT232 或 CH340 USB-TTL；
- 如果实测约 `1.8 V`，另购可靠的 1.8 V UART 适配器或双向电平转换器；
- 细针表笔、迷你测试钩、PCB 固定夹；
- 可选 8 通道逻辑分析仪。

第一次只读连接：

```text
主板 GND  -------- USB-TTL GND
主板 TX   -------- USB-TTL RX
主板 RX   -------- 暂时不接
主板 VCC  -------- 绝对不接
```

H700 RGSP 当前已知控制台参数为：

```text
115200 baud
8 data bits
no parity
1 stop bit
no hardware flow control
```

即 `115200 8N1`。先在串口软件中打开端口，再让设备完全断电冷启动并保存完整日志。

只有确认日志正常、确认板端 RX 电平与 USB-TTL TX 相容后，才连接：

```text
主板 RX   -------- USB-TTL TX
```

首次接 TX 可串联 `1 kΩ` 电阻作为额外保护。若只需抓 U-Boot、Linux kernel 和 Android early-init 日志，通常长期只接 GND 与板端 TX 就够了。

## 7. H700 Android 开发中万用表能解决什么

万用表适合：

- 找公共 GND；
- 判断 UART 是约 1.8 V 还是 3.3 V；
- 初筛 UART TX；
- 确认某电源轨是否存在；
- 断电检查线材和焊点是否连通；
- 排查接线是否意外短路。

万用表不能解决：

- 读取 UART 文本；
- 判断波特率；
- 分析高速数字波形；
- 证明一个 3.3 V 测试点一定是 UART；
- 代替 eMMC 备份、ADB、逻辑分析仪或示波器。

对当前 Android 移植，万用表的直接目标不是“修 Android”，而是安全接通 `ttyS0`，从而观察：

1. U-Boot 实际选择了哪张 TF 卡和哪个 boot 分区；
2. kernel 是否完成驱动初始化；
3. handoff init 是否成功挂载 Android system/vendor；
4. Android init、SELinux、Binder、vold、SurfaceFlinger 停在哪一步；
5. 失败后能否无损回到原厂 Linux。

## 9. 第一次实机协作的停止条件

出现任一情况立即断电并停止：

- 表笔滑动并同时接触两个焊盘；
- 主板、电池或线材明显发热；
- 闻到异味或看到烟；
- 电池鼓包、破损；
- 不确定当前旋钮是否在电流档；
- 不确定红表笔是否仍插在 `VΩHz`；
- 测得候选 UART 电平高于 `3.6 V`，却准备接 3.3 V USB-TTL；
- 设备行为突然与测量前不同。

断电后保留现场照片和读数，不继续碰运气。下一步应先复核档位、接线和测试点身份。

## 10. 当前推荐执行顺序

1. 用蜂鸣档完成表笔短接自检。
2. 用 `V⎓ 20` 档测一节 AA/AAA 电池，拍下档位和读数。
3. 给 H700 主板正反面拍清晰照片，标出所有成组测试点和接口外壳。
4. 主板断电，先找 GND，记录通断和电阻。
5. 主板通电，只测候选点直流电压。
6. 根据实测电平选择 3.3 V 或 1.8 V UART 设备。
7. 只接 GND 和板端 TX，抓取第一次完整冷启动日志。
8. 日志归档到 `out/logs/uart/<device>/<date>/`，同时记录测试固件 SHA-256。

RGSP 的首次连接与 Windows 日志抓取命令见 `docs/RGSP_UART_FIRST_CONNECTION_20260829.md`。
