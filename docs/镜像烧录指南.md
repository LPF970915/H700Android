## 烧录步骤

### 方法1: 直接终端原始块写入（推荐）
1. 确认目标为 Disk 3、USB 序列号 `000000001539`、容量
   `125069950976` 字节。
2. 以管理员身份打开 PowerShell。
3. 执行：

```powershell
cd D:\Works\H700Android
$run = "D:\Works\H700Android\out\rgsp-v5c-direct-flash-$(Get-Date -Format yyyyMMdd-HHmmss)"
New-Item -ItemType Directory -Force $run | Out-Null
PowerShell -NoProfile -ExecutionPolicy Bypass -File `
  D:\Works\H700Android\tools\direct_flash_v5.ps1 `
  -ImagePath D:\Works\H700Android\out\H700_Android_SingleCard_v5c_SettingsDpad.img `
  -DiskNumber 3 -RunDirectory $run
```

4. 只有当 `result.json` 的状态为
   `DIRECT_WRITE_AND_READBACK_VERIFIED` 时，才允许安全弹出并上机。

### 方法2: 使用 Rufus（分发备用）
1. 运行 Rufus
2. **设备**: 选择你的SD卡读卡器
3. **引导类型选择**: 点击"选择"，选择 H700_Android_SingleCard_v3b.img
4. Rufus会自动检测为DD镜像
5. **分区类型**: 保持默认（会自动识别GPT）
6. 点击"开始"
7. 等待写入完成（约10-30分钟，取决于读卡器速度）
8. 完成后点击"关闭"

### 方法2: 使用 balenaEtcher
1. 运行 balenaEtcher
2. 点击 "Flash from file"，选择 H700_Android_SingleCard_v3b.img
3. 点击 "Select target"，选择你的SD卡
4. 点击 "Flash!"
5. 等待完成
6. Etcher会自动验证写入结果

### 方法3: 使用 Win32 Disk Imager
1. 运行 Win32 Disk Imager（需要管理员权限）
2. **Image File**: 选择 H700_Android_SingleCard_v3b.img
3. **Device**: 选择你的SD卡盘符
4. 点击 "Write"
5. 确认警告对话框

## 烧录后测试

### 1. 插卡启动
- 将烧录好的SD卡插入H700的 **TF1卡槽**
- 确保TF2卡槽为空（或拔出其他卡）
- 接通电源，按电源键开机

### 2. 串口监控（可选但推荐）
- 使用USB-TTL转接器连接H700的UTRA串口
- 波特率: 115200
- 数据位: 8
- 停止位: 1
- 无校验
- 使用串口工具（如PuTTY、MobaXterm）监控启动日志

### 3. 预期启动流程
1. Bootloader启动信息
2. Linux内核启动
3. Android系统启动
4. **首次启动会弹出桌面选择对话框**:
   - 选择 "AT4K启动器"（不要选择RG HOME）
   - 建议选择"始终使用"（Always）

### 4. 如果误选了桌面
如果选错了桌面启动器，通过串口执行：
`ash
# 进入shell
adb shell

# 清除默认启动器设置
pm clear com.android.launcher3

# 或者直接设置AT4K为默认
pm enable com.at4k.launcher
pm set-home-activity com.at4k.launcher/.MainActivity
`

## 常见问题

### Q: 烧录后按电源键无反应？
A: 检查：
1. SD卡是否插在TF1卡槽（不是TF2）
2. 电源是否正常接通
3. 电池是否有电
4. 通过串口查看是否有任何启动信息

### Q: 烧录工具提示SD卡写保护？
A: 检查SD卡侧面的物理锁定开关，确保在解锁位置

### Q: 烧录速度很慢？
A: 正常现象，58GB数据写入需要10-30分钟
- USB 2.0读卡器: 约30-60分钟
- USB 3.0读卡器: 约10-20分钟

### Q: Windows提示"需要格式化SD卡"？
A: **不要格式化！** 这是正常现象，因为Windows不识别Android的ext4分区
- 直接弹出SD卡即可

### Q: 启动后进入了RG HOME而不是AT4K？
A: 参考上面"如果误选了桌面"部分，通过串口重置
