# ROC OS 0.0.4 各机型首次开机说明

1. 把烧录好的系统卡插入 **TF1**，只按电源键开机，等机型菜单启动。新卡默认进入 **35XX H** 这一组。
2. 按下表切到本机面板。**音量键每次短按并松开**，松手后机器会自动重启。需要按两次时，等第一次重启、菜单启动后再按第二次。如果当前面板黑屏，也可以按表切换。
3. 看到菜单后，用 **十字键左／右** 选中和机身一致的型号。按 **↓** 到“保存为启动默认”，按 **A** 勾选，再按 **↓** 到“启动系统”，按 **A**。等“加载中，请稍后”结束即可进入 Android。下次只按电源键就能直接启动。

| 你的掌机 | 从新卡默认档按音量键 | 菜单中选 |
| --- | --- | --- |
| RG35XX H | 0 次 | 35XX H（默认） |
| RG35XX Plus | 0 次 | 35XX Plus |
| RG35XX 2025 | 0 次 | 35XX+（2025） |
| RG28XX | 0 次 | 28XX |
| RG35XX Pro | 0 次 | 35XX Pro |
| RG35XX SP | 0 次 | 35XX SP |
| RG40XX V | 音量减 1 次 | 40XX V |
| RG40XX H | 音量减 1 次 | 40XX H |
| RG34XX SP | 音量减 2 次 | 34XX SP |
| RGSP | 音量减 2 次 | RGSP |
| RG34XX（直板） | 音量加 2 次 | 34XX（本组唯一选项） |
| RGCubeXX | 音量加 1 次 | CubeXX（本组唯一选项） |

**只想启动这一次**，选中型号后直接按 **↓、↓、A**。**已保存默认、想换机型**，关机后按住音量减再按电源，菜单出现后松手。此时从已保存机型所在组开始，音量减按 **35XX H 组 → 40XX 组 → 34XX SP／RGSP 组 → 直板 34XX → CubeXX** 循环，音量加反向。
