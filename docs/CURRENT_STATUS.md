# ROC OS 当前版本说明

更新日期：2026-11-17。当前正式版本为 **0.0.3**，一份系统卡镜像通过启动菜单选择十二种 H700 机型。用户已确认其基础 Test11 的摇杆修复在 **RG35XX H** 上有效；本次将该实现保留并更新包内版本，封装为正式 0.0.3。

镜像网盘是长期更新的统一下载入口，包含最新正式版、历史版本和测试镜像；Git 公布正式版信息时，新镜像同步到网盘，目前已包含 0.0.3。文件身份与分发范围见[下载与校验](PUBLIC_DOWNLOADS.md)，封装变化及校验见 [0.0.3 发行说明](ROC_OS_0.0.3_20261117.md)。历史测试问题保留在对应记录中。

## 已包含的功能

- 十二机型选择、保存启动默认与重新选择入口，不按运存或摇杆数量限制 Android 启动。
- 三档面板试屏、按具体机型加载显示配置，以及确认后的“加载中，请稍后”提示。
- Navigation18 和框架导航保护：短按立即响应，按住 400ms 后每 160ms 连发，同一会话达到 10 秒停止；松开／回中后重新放行，熄屏和窗口变化清理旧会话。
- 公共摇杆驱动：正确检查 H700 ADC 模式位，L3／R3 点击与方向采样独立，保留中心校准、唤醒回中和有界恢复保护。
- 默认 2GiB TF1 交换空间、Lid4 翻盖服务、时间默认源及既有 USB、user／Enforcing 和生产签名配置。

## 机型与启动

| 分辨率 | 菜单中的机型 |
| --- | --- |
| 720×480 | 34XX、34XXSP、RGSP |
| 720×720 | CubeXX |
| 640×480 | 35XX Plus、35XX+／35XX 2025、28XX、35XX H、40XX H、40XX V、35XXSP、35XX Pro |

翻盖服务仅对 34XXSP、RGSP、35XXSP 开启；其余机型按各自的无杆、单杆或双杆配置处理。28XX 保留竖屏横用配置。相同分辨率仍可能需要不同的面板初始化，十二项菜单全部开放不代表所有实物已经完成验证。

使用至少 64GB TF1，首次测试将 TF2 留空。只按电源进入首次菜单，初始试屏为 35XX H 的 640×480。若画面不可读，完整按下并松开音量减，在 **35XX H 640×480 → 34XXSP 720×480 → CubeXX 720×720** 间切换并重启返回菜单；音量加反向切换。看到菜单后选择实际机型并确认。保存默认后下次直接启动；电源＋音量减保留重选入口。

首次准备数据区和 2GiB 交换文件需要等待，后续启动复用交换文件。交换空间不足或启用失败会继续启动 Android；交换空间不能保证解决全部应用闪退。
