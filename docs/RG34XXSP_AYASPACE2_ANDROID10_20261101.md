# AYASpace 2 / Pocket Museum Android 10 适配测试

2026-11-01。独立应用增量，父运行环境为原 64GB 卡上的 ARM64 Test2a，RG34XXSP / H700 / 2GB / Android 10。每次控制前按现卡 serial、CID、profile、容量和 image marker 守卫核对；没有改写系统分区、全局机型、系统按键表、现有模拟器或镜像。

原始 APK 的 [API31 安装失败记录](RG34XXSP_AYASPACE2_COMPATIBILITY_20261101.md) 继续成立。用户随后明确要求移植，现提供独立签名的 `0.3.3-a10-h700-r9` **兼容测试包**，不把降低 minSdk 等同于完整兼容。

## 交付与修改

- 本地 APK：`out/ayaspace2-20261101/PocketMuseum_0.3.3_H700_Android10_r9.apk`。
- SHA-256：`fc300ecd1be74d9d0273b4f4b523959d3423aed2e15a17014283439e1256768b`。
- 仍仅含 ARM64 native 库；普通应用 UID，去除原包的 system shared UID，未申请平台签名。
- API29 legacy READ/WRITE 存储授权替代所有文件访问接口；适配外置卷目录、启动画面、系统栏/全屏、窗口尺寸、震动及键盘布局通知。
- 在应用内接入 H700，不修改系统身份；只有 ANBERNIC 的 scan304/A 在应用中转换为 BUTTON_A，X/Y 没有交换。
- 旧 SQLite 不支持两条 UPSERT，导致页面显示扫描完成但无入库。现用事务内 INSERT OR IGNORE 加条件 UPDATE 保留原状态语义；没有替换系统 SQLite。
- 游戏内增加短按 Select+Start 呼出暂停，系统 Menu 仍回桌面，单独长按 Select 的鼠标服务不改。
- 原 APK 的 1,129 个无关资源/native/assets 条目逐项 SHA 保持；ROM、测试媒体和用户配置不在新 APK 中。

[本地构建说明](../tools/ayaspace2/README.md)。构建全程通过低压力包装器；没有放宽资源限制，也没有重编完整系统或 Godot 引擎。
